# Creating Backup Jobs


To create a backup job, do the following:

1. [Check prerequisites and limitations](backup_job_prerequisites.md).
2. [Launch the New Backup Job wizard](backup_job_launch_wizard.md).
3. [Specify a job name and description](backup_job_general_settings.md).
4. [Selects VMs to backup](backup_job_assign_vms.md).
5. [Specify a backup repository where backups will be stored and configure backup settings](backup_job_destination.md).
6. [Create a schedule for the backup job](backup_job_schedule.md).
7. [Finish working with the wizard](backup_job_review.md).
