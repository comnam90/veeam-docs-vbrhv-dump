# Configuring Veeam Plug-in for Oracle Linux Virtualization Manager and Red Hat Virtualization


To start working with Veeam Plug-in for OLVM and RHV, perform a number of steps for its configuration:

1. [Configure backup repositories where Veeam Backup & Replication will store backups of oVirt VMs.](configure_repository.md)
2. [Connect to oVirt KVM Manager that administer oVirt resources you want to protect.](connecting_manager.md)
3. [Deploy workers that will transfer backup traffic.](workers.md)
4. [[Optional] Configure email settings and notifications.](general_settings.md)
